# Modrinth listing

[modrinth.md](modrinth.md) contains the project settings, gallery captions and description for Preheat's Modrinth page.

Create the project and upload its artwork before enabling version publishing. Set the repository secret `MODRINTH_TOKEN` and variable `MODRINTH_PROJECT_ID` as described in [releasing](../releasing.md#setting-up-publishing). The release workflow uploads versions; it does not create the project page.

| Asset                     | Repository path                              |
| ------------------------- | -------------------------------------------- |
| Icon                      | `src/main/resources/assets/preheat/icon.png` |
| Banner                    | `docs/images/banner.png`                     |
| Video Settings screenshot | `docs/images/video-settings.png`             |
| Preheat screen screenshot | `docs/images/settings.png`                   |
| Loading-screen animation  | `docs/images/loading-screen.gif`             |

Preheat is distributed through [Modrinth](https://modrinth.com/mod/preheat) and [GitHub Releases](https://github.com/lewisgibson/preheat/releases).
